# Клубок: каталог схем вязаных игрушек

Учебный проект (МДК 05.01). Веб-приложение на Flask с базой данных SQLite: каталог схем с категориями, поиском, фото, избранным и комментариями.

## Возможности

- Каталог схем, поиск по названию и материалам, фильтры по категории и уровню
- Страница схемы с материалами и пошаговым описанием
- Регистрация и вход, пароли хранятся в виде хэша
- Избранное и комментарии для вошедших пользователей
- Администратор добавляет, изменяет и удаляет схемы с фото
- Страницы «Азы вязания», «О сайте», «Контакты»

## Что понадобится

- Python 3.10 или новее
- Библиотека Flask (устанавливается одной командой, см. ниже)

## Запуск

1. Скачайте проект и откройте папку с файлом `app.py` в терминале.
2. Установите Flask:

   ```
   python -m pip install -r requirements.txt
   ```

3. Запустите сайт:

   ```
   python app.py
   ```

4. Откройте в браузере адрес `http://127.0.0.1:5000`.

База данных `vyazanie.db` создаётся автоматически при первом запуске, вместе с пятью категориями и четырьмя стартовыми схемами.

## Роли

- **Первый зарегистрированный пользователь** автоматически становится администратором и видит пункт меню «Добавить схему».
- Остальные пользователи могут добавлять схемы в избранное и писать комментарии.
- Гости могут смотреть каталог и страницы схем.

## Тестовые данные

Чтобы заполнить базу тестовыми данными (10 пользователей, 8 схем, 12 комментариев, 10 записей в избранном), выполните:

```
python load_test_data.py
```

Пароль всех тестовых пользователей: `test1234` (имена `test_anna`, `test_masha` и т.д.). Повторный запуск ничего не дублирует.

## Фоновое видео

Чтобы на сайте появилось видео-фон, положите свой файл `bg.mp4` в папку `static`. Без него сайт показывает цветной фон.

## Структура проекта

| Файл или папка | Назначение |
| --- | --- |
| `app.py` | Серверная часть: маршруты, авторизация, работа с базой |
| `seed.py` | Стартовые схемы |
| `schema.sql` | Структура базы данных |
| `test_data.sql`, `load_test_data.py` | Тестовые данные и скрипт их загрузки |
| `templates/` | HTML-шаблоны страниц |
| `static/` | Стили (`style.css`) и загруженные фото (`uploads/`) |

## Настройки

- Переменная окружения `SECRET_KEY` задаёт секретный ключ сессий (в проекте стоит значение по умолчанию, перед публикацией в интернет его нужно заменить).
